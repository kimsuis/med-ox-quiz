# 의대 OX 퀴즈 · 기출

혼자 쓰는 의대 공부 사이트. **기출(출족·작년 시험)** 과 **자작 OX(교수님 강조점만)** 를 한곳에서 풀고, 간격 반복으로 복습한다.

- 사이트: https://kimsuis.github.io/med-ox-quiz/
- 기록 동기화: 설정 › 기기 간 동기화에 gist 권한 토큰 → 내 GitHub 비밀 gist(`med-ox-quiz-progress.json`)로 모든 기기 기록이 합쳐짐
- 복습: 맞히면 1→3→7→14→30→60일 뒤, 틀리거나 ‘모르겠다’면 오늘 다시. 시험일 전날을 넘겨 미루지 않음. 복습 세션에서 틀린 건 세션 끝에 한 번 더
- 별표(★): 헷갈려서 다시 볼 문제에 직접 찍는 표시. 맞혀도 안 빠짐

## 기출

- 강의마다 출족 출처: 올해 개별 올출 > 올출 합본 > 작년 출족(작출). 2025 실제 시험은 교수별로 따로
- 문항마다: 원본 문제 그림 · 보기 버튼 채점 · 💡 한 줄 핵심 · 초보자용 쉬운 해설(올해 강의록 → 올해 정리족 → 작년 정리족 → 부족하면 [외부]) · 근거 쪽수 · 출족 원래 풀이
- 강의 화면: 교수 변경 이력, 올해 시험 정보, 연도·범위 주의, 빈출 개념, ‘지금 교수·범위만’ 거르기, 쫙 보기(쭉 넘겨 읽기)
- **암호화**: 출족·시험지는 학교 자료라 `data/g/`에 AES-GCM으로 암호화해 올린다. 키는 `_build/KEY.txt`(커밋 안 함). 설정 › 기출 잠금에 한 번 넣으면 동기화된 다른 기기로 자동 전달

### 다시 만들기 (`_build/`, 커밋 안 함)
1. `lectures.py` — 강의 목록과 출족 출처(새 올출이 올라오면 여기서 바꿈)
2. `python -I _build/extract.py [강의id…]` — 출족 표를 문항 단위로 잘라 `raw/`, `img/`
3. `python -I _build/parse_exam.py` — 작년 시험지
4. 해설: `EXPLAIN_GUIDE.md` 지침대로 `explain/<강의id>.json` (근거 경로 `refs.json`, `make_refs.py`)
5. 문제 글: `TEXT_GUIDE.md` 지침대로 `text/<강의id>.json` (사진·그래프만 그림, 나머지는 글)
6. `python -I _build/pack.py` — 합쳐서 암호화 → `data/g/`
7. 커밋·푸시 (직접)

## 자작 OX 세트 추가

`data/sets/endo26-bae.js`를 복사해 `data/sets/<id>.js`로 만들고 `data/sets.js`에 한 줄 추가.
`gLectures`에 기출 강의 id를 적으면 그 강의 화면에 자작 OX 바로가기가 생긴다.
문항 `id`를 바꾸면 그 문항 기록이 사라지니 문장·해설만 고칠 것.
