# 의대 OX 퀴즈

교수님이 짚어 준 **강조 범위만** 골라 만든 OX 퀴즈. 과목·교수님마다 세트를 하나씩 추가해서 계속 쓴다.

- 사이트: https://kimsuis.github.io/med-ox-quiz/
- 기록 동기화: 설정 › 기기 간 동기화에서 gist 권한 토큰을 넣으면 내 GitHub 비밀 gist(`med-ox-quiz-progress.json`)로 모든 기기 기록이 합쳐짐
- 복습: 맞히면 1→3→7→14→30→60일 뒤, 틀리거나 ‘모르겠다’면 0단계로 오늘 다시. `examDate`가 있으면 시험 전날을 넘겨 미루지 않음. 복습 세션에서 틀린 문제는 세션 끝에 한 번 더
- 별표(★): 헷갈려서 다시 볼 문제에 직접 찍는 표시. 맞혀도 안 빠짐
- 키보드: O·1 = O, X·2 = X, ↓·3 = 모르겠다, → / Enter = 다음 (시험 모드 ← 이전), S = 별표

## 새 세트 추가하기

1. `data/sets/endo26-bae.js`를 복사해서 `data/sets/<과목약어><연도>-<교수>.js`로 만든다
2. 항목 채우기
   - `id`: 파일 이름과 같게 (기록 키로 쓰이니 한 번 정하면 바꾸지 말 것)
   - `subject`, `term`: 홈에서 이 값으로 묶임 (예: `"내분비학"`, `"본1-2 · 2026"`)
   - `lectures`: 강의록 별칭 (`P1: "1번 ppt · ○○"`)
   - `focus`: 강조 범위 `{ lec: "P1", page: 8, label: "…" }`
   - `topics`: 주제 = 강조 포인트 하나. `src: "P1 8p"`, `summary`: 핵심 정리 줄
   - `questions`: `{ id, t: 주제id, a: true(O)/false(X), q: 문장, why: 해설, ex: "2025"(기출 연도, 선택) }`
3. `data/sets.js`의 `SET_FILES`에 경로 한 줄 추가
4. 커밋·푸시하면 1~2분 뒤 사이트에 반영

문항 `id`를 바꾸거나 지우면 그 문항의 기록은 사라진다. 고칠 땐 `q`/`why`만 바꾸는 게 안전.
